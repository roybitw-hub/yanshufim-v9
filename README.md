# ינשופים V9

מערך לימודים לסמסטר, מעל נושן. נושן הוא מקור האמת: האפליקציה קוראת וכותבת אליו דרך ה־API, ולא שומרת נתונים משלה.

## מה יש בגרסה הזו

- **בית** (נייד ודסקטופ): הירו עם הינשוף, הודעות מתחלפות, "היומן שלי" (יום/שבוע/חודש), טיילים, כרטיסיות נעוצות, "מה חשוב עכשיו" עם החלקה, "בהמשך", הקורסים שלי.
- **לו״ז** שבועי עם ניווט, **קורס** (מפת סמסטר, מה למדנו, מטלות ושלבים, שיעורים, מבחנים), **פריט** (שיעור / מטלה / מבחן / הודעה) עם עדכון סטטוס, **תיבה**, **משימות**, **הוספה**, **מצב המערכת**.
- **מנוע "מה חשוב עכשיו"** (`lib/feed.ts`): מועדים קרובים ובאיחור, הצעד הבא במטלה, מפגשים שלא תועדו, הקלטות בלי נוכחות, משוב שדורש פעולה. לכל אות יש מפתח יציב; "נקרא" / "נעוץ" נשמרים במאגר **ינשופים — מצב פיד** בנושן.
- **נעילה בסיסמה** עד שנוסיף כניסה עם Google.
- אפשר להתקין למסך הבית (manifest + אייקון הינשוף).

בלי `NOTION_TOKEN` האפליקציה רצה על נתוני דמו (`lib/demo.ts`).

## משתני סביבה (Vercel → Settings → Environment Variables)

| משתנה | חובה | מה זה |
|---|---|---|
| `NOTION_TOKEN` | כן | ה־Internal Integration Secret של האינטגרציה "ינשופים V9" |
| `APP_PASSWORD` | כן | הסיסמה לכניסה לאפליקציה |
| `SESSION_SECRET` | כן | מחרוזת אקראית ארוכה לחתימת העוגייה |
| `NOTION_DS_COURSES` / `NOTION_DS_ITEMS` / `NOTION_DS_FEED` | לא | מזהי מאגרים, אם יזוזו |

## פיתוח מקומי

```bash
npm install
cp .env.example .env.local   # ולמלא
npm run dev
```

## מבנה

- `lib/notion.ts` — לקוח REST מינימלי (Notion-Version 2025-09-03, data sources), תור בקצב ~3 בקשות לשנייה, ניסיון חוזר ב־429.
- `lib/data.ts` — קריאה של כל הנתונים בשלוש שאילתות, מטמון 45 שניות, כתיבות (`כותב = אפליקציה`).
- `lib/schedule.ts` — פריסת מפגשים שבועיים, ביטולים, אירועים ומועדים.
- `lib/feed.ts` — אותות, הודעות, מספרים.
- `lib/config.ts` — סמסטר, צבעים ואייקונים לכל קורס, חריגים במערכת השעות (מיקרו: הרצאה + תרגיל).
- `lib/icon-data.ts`, `lib/owl-svg.ts` — שפת האייקונים והינשוף (נוצרו מהקנבס).
